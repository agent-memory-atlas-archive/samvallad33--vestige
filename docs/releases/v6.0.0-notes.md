# Reflex: every agent hook reaches Vestige

Vestige v6.0.0 makes the store part of every tool call an agent makes. Reflex is
a tool the agent's own hooks call directly, so each firing reaches the server
that owns the store and leaves a line in a hash-chained Hook Ledger.

- **Operator stops become memory.** Each gate receipt is checked against the
  gate's digest chain, saved as a stop memory linked to its rule, told to the
  stopped agent once, and linked to the permit or compliant path that answered it.
- **Context manifest.** Reflex keeps the exact memories each agent and subagent
  holds. A memory the agent already holds word for word is folded out of later
  results, the memory hook never injects it twice, and every Vestige hook shares
  one budget per turn. `vestige reflex --replay` measures the fold on your own
  recorded sessions.
- **Failure Pairing.** A failed call is classified by a fixed table, saved once
  under its signature tag, and paired with the fix the next time the same
  command succeeds. When an earlier failure has a recorded fix, the agent hears
  it right away.
- **Stale-belief push.** When one agent edits, demotes or suppresses a memory,
  every other agent that held it is told before its next action, with the
  successor and the receipt.
- **Compaction survival.** Before compaction Reflex checkpoints the memories the
  agent holds; after it, the summary is audited by exact id and anything dropped
  comes back by handle, decisions first, each as its current version.

## Operator Lite carries every per-call rule

Operator Lite now ships every per-call rule from OP-000 to OP-025, so the free
gate sets the standard for what an agent may do on its own:

- the floor, a recursive delete of a root, a home folder or a parent of the
  working directory, refused in every mode
- root reach, repo code run, vulnerable writes and agent arming
- the harmful chain, a second spelling of a stopped action and a found key
- protected files with `protect`, remote deletes, the runaway brake and the
  watch turnover after each compaction
- the evidence lock: an agent can read its own transcripts and the shell's
  history, but erasing, emptying or rewriting them is the owner's call

The paid Operator keeps the owner's laws, the Board, the Letter, onboarding and
one record of stops across every session, host and agent CLI on the machine.

## Smaller fixes

- Tag recall returns a page of summaries by default with a handle to the next
  page, and a single id still returns the whole memory.
- `smart_ingest` answers in its compact profile by default.
- `causal_walk` scans a bounded window by default.
- Provenance accepts `memoryId` or `memory_id`, and `memory get` resolves a
  unique id prefix.

Memory stays local by default. Nothing in Reflex blocks a call; the Operator gate
stays the only thing that can stop one, and it fails closed.

See [docs/REFLEX.md](https://github.com/samvallad33/vestige/blob/v6.0.0/docs/REFLEX.md)
for how each hook firing is handled.
