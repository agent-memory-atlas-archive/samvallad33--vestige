# Retroactive Salience Backfill returns

Vestige v5.0.1 brings Backfill back to the Strata memory path, including personal
and companion memories. New information can raise or lower the salience of
earlier memories through exact shared entities and recorded relationships.
`causal_walk` keeps its separate backward-investigation role.

For example, Maya's new allergy fact can raise the earlier memory that Maya
felt off after dinner at Bangkok Garden. The link is `person:Maya`; it does not
assert that the restaurant serves peanuts or change another person's memory.
Exact-handle recall uses the updated salience when an agent plans her next meal.

- Automatic Backfill on saves; disable it with `VESTIGE_BACKFILL_AUTOFIRE=0`.
- Manual `backfill` MCP and `vestige backfill` commands.
- Bounded upward and downward updates, change receipts, dry runs, pair
  idempotency, and exact-score undo.
- Updated 5.0.1 product packages and installer binary pins.
- The existing free foundation remains: hooks for recognized dangerous calls,
  one-use owner permits, gate decision receipts, and shared Strata memory.

Memory remains local by default. Exact identities and recorded evidence are
required; Backfill does not add embeddings, fuzzy lookup, or inferred food
ingredients. Hook coverage depends on supported integrations and routed calls.

This file is prepared release copy. Build and test results, six target archives
and checksums, and owner approval must accompany the final published release.
